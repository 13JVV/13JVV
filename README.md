### 🧭 일하는 방식

- **작게 먼저 출시합니다.** 핵심 기능부터 내고, 실제 사용 흐름을 확인한 뒤 확장합니다.
- **AI 결과는 사람이 확인하게 합니다.** AI가 틀릴 수 있는 지점에 확인 단계를 넣습니다.
- **모르는 건 모른다고 보여 줍니다.** 데이터가 없거나 모호하면 단정하지 않고 그 상태를 드러냅니다.
- **말보다 만들어서 비교합니다.** 의견이 갈리면 두 안을 직접 구현해 보고 정합니다.
