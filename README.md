### 팀장 경험 (4회)

- **빅콘테스트 AI데이터활용 캡스톤 (4인)**: 브랜치 · 리뷰 · 데이터 보호 규칙을 먼저 세우고 의사결정 로그로 같은 근거를 보게 했습니다. 문제 정의, 분석 설계, AI 에이전트 구현을 맡았습니다.
- **교내 AI 문제해결 경진대회 (5인)**: 네 전공이 다르게 보던 안전 문제를 "인력과 예산을 어디에 먼저 쓸까"라는 한 질문으로 묶고, 두 화면안을 비교해 팀원 안을 채택했습니다.
- **생성형 AI 구독 모델 분석 (4인)**: 설문 초안에서 모든 속성이 앞서는 선택지를 발견해 일정을 늦추더라도 다시 설계하자고 결정했고, 유효 응답 113명을 모았습니다.
- **강화학습 PPO (3인)**: 10개 설정을 3개 시드로 돌리는 실험을 맡고, 평균뿐 아니라 시드 간 편차까지 보는 기준으로 최종 설정을 골랐습니다.

<br>

### 일하는 방식

- **MVP로 먼저 내고, 반응을 보고 고칩니다.** 핵심 기능 하나로 출시한 뒤 사용자 피드백과 스토어 심사 의견을 다음 우선순위로 바꿉니다.
- **기능 우선순위는 사용자의 선택으로 정합니다.** "다 중요하다"는 답 대신 사용자가 무엇을 고르는지 실험으로 확인하고, 팀의 가정이 틀렸다면 데이터를 따릅니다.
- **AI 기능에는 검증과 사람의 확인을 붙입니다.** 출시 전에 정답을 아는 데이터로 시험하고, 틀릴 수 있는 지점에는 사용자가 확인하는 단계를 넣습니다.
- **모르는 것은 모른다고 화면에 보여 줍니다.** 데이터가 없거나 모호하면 그럴듯하게 채우지 않고 "확인 필요", "판정 불가"로 알려 줍니다.
